# 五步抓主升（量能四象限+标杆量持仓法）

- 来源: 用户提供的短线教学视频整理 / 2026-09-12
- 关联代码: `stock_monitor/engine/rules_mainwave.py`（五步引擎）
- 与八阶段的关系: mainforce.py判主力**性质**（吸筹/出货），本卡管**操作纪律**
 （何时进场/何时拿住/何时清仓）——互补不重复

## 一句话结论

三金叉定趋势，量能破五触发进攻，标杆量做持仓纪律：低于标杆量阴阳都拿，高于标杆量第一次观察、第二次清仓。

## 核心规则

### 量能四象限（标杆量判定表）

```
标杆量(N-1原则): N=触发后连续建仓(放量)天数, 标杆量=第(N-1)根量柱高度;
                仅1天建仓则当天量即标杆量
低于标杆量+阳线 = 拉升量  → 坚定持仓
低于标杆量+阴线 = 洗盘量  → 坚定持仓
高于标杆量(第1次) = 一次出货 → 持仓观察(不动)
高于标杆量(第2次) = 二次出货 → 清仓离场
铁律: 低于标杆量无论阴阳都持仓; 高于第一次不动,第二次才清仓(双顶止盈)
```

### 五步流程

```
① 定趋势: 5日线上穿10日线 + 5上穿20 + 10上穿20, 三金叉须在5个交易日内完成
        (缺一不可,时间窗口是主升浪的必要条件)
② 找信号: 定势后最多等7个交易日, 当日量 > 前5日最高量 = "量能破五"触发
        (无论阴阳,量达标即触发——阴量启动型也是进攻信号)
③ 找标杆: 从触发日起数连续放量天数N, 按N-1原则定标杆量
④ 持仓:   每日量对照标杆量,按四象限表执行
⑤ 卖点:   二次出货量出现当天清仓
```

### 止损防守

```
触发日价格偏高(如T字板) → 跌破触发日最低价立即止损
5日均线: 收盘跌破 → 减仓或清仓观望
20日均线: 最终逃命线,收盘跌破 → 坚决清仓不补仓
```

### 选股时点

9:25开盘价出来后筛选"5日内三金叉"股，再看当日量能是否可能破五。
两个条件不齐备不做——宁空仓不硬做。

## 三种验证行情

1. 低位横盘爆发型（横盘7-8月后启动，位置低）
2. 快速连涨型（7天5涨，4天连续建仓）
3. 阴线启动型（阴量但破五+三金叉齐备，仍是进攻信号）
