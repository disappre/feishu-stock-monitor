# 深度强化学习改造网格策略（Ilan 3.0 AI）

- 来源: https://www.mql5.com/zh/articles/17455 / 2026-09-09
- 关联代码: 暂未实现（定位：方法论警示卡，不直接落地）

## 一句话结论

用动态Q-table+DRL替换Ilan网格EA的硬编码加仓规则，本质是给"逆势马丁格尔"加自学习能力——方向新颖但风险本质未变。

## 核心内容

```
Ilan原始机制: 价格反向不止损，而是按网格间距(GridSize)加倍加仓，
             拉低均价等回归——典型马丁格尔，低波动期有效、单边市爆仓
文章改造: 动态Q-table状态(波动率/持仓数/浮亏) → 学习"加仓/持平/暂停"决策
         摒弃硬编码规则，让加仓时机自适应
```

## 适用与失效（本卡重点：为什么本项目不跟进）

- **马丁格尔的尾部风险不因AI化而消失**：DRL优化的是加仓节奏，但"无限逆势加仓"
  的爆仓结构仍在。文章标题吸引人，风险披露不足
- 对本项目的可取之处：**状态设计**(波动率/持仓数/浮亏作为决策特征)值得借鉴；
  动态Q-table在状态空间离散化处理的思路，若未来做"信号过滤器强化学习"
  (学"何时信聚类信号")可参考
- 强化学习在金融落地的普遍陷阱：奖励函数=收益时，agent会学会隐藏的加杠杆行为；
  需要风险调整奖励(如夏普/最大回撤惩罚)
