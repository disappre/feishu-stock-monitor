# 元启发式优化算法（A3人工原子算法）

- 来源: https://www.mql5.com/zh/articles/18958 / 2026-09-09
- 关联代码: 暂未实现（用途：监测系统规则参数寻优，替代手工调参）

## 一句话结论

以化学反应为灵感的元启发式优化（原子=候选解，电子=决策变量，共价键=开发，离子键=探索），用于策略参数寻优而非直接产生交易信号。

## 核心规则

```
用途: 优化"指标周期/阈值/仓位/时间过滤"等参数组合，不产生买卖信号
流程: 随机原子种群 → 目标函数评估 → 共价键算子(复制当前最优解,开发)
      + 离子键算子(探索搜索空间) 迭代 → 直至终止条件
默认参数: popSize=10, covalentRate=0.1（来自文章）
```

## 适用与失效

- 适用: 规则引擎参数寻优（如 watchlist.yaml 中各阈值联合优化——现在是手工拍的）
- 失效/风险: 元启发式算法在噪声目标函数上极易过拟合——用回测收益当目标函数会找到"历史上完美"的参数。**必须用样本外验证**（本文作者也未充分讨论此点，是普遍盲区）
- 关键教训(作者亲述): 原始文献表述模糊、算子定义不完整，实现全靠自主解读——阅读学术算法文章时，**伪代码可复现性差是常态**，落地时要有自己的工程判断

## 与本项目关系

当前8个规则的阈值（0.618/2.0σ/1.5量比等）全部来自文献默认值。
正确用法：本地SQLite已存250根×300只日线 → 以"信号后N日胜率"为目标函数
做参数寻优 → 样本外验证 → 才允许更新到 watchlist.yaml。
同类可选项：遗传算法、贝叶斯优化（后者对小目标函数评估次数更友好）。

## 参数依据

- popSize/covalentRate默认值来自来源文章【待验证】；未做A股回测

## 2026-09-10 全池寻优实证（300只×250根，前瞻5日，日期7:3切分）

| 规则 | 最优参数 | 训练胜率 | 测试胜率 | 回撤 |
|------|---------|---------|---------|------|
| ma_cross | (20,30) | 54.4% | 46.1% | -8.3pt |
| price_surge | 4.0% | 51.2% | 46.2% | -5.0pt |
| volume_surge | (1.5,10) | 51.1% | 47.4% | -3.7pt |
| rsi | (80,25) | 53.9% | 46.1% | -7.8pt |
| candle_div | (70,25) | 64.3% | 45.7% | **-19pt ⚠️过拟合** |
| fractal_break | (14,100) | 55.0% | 46.0% | -9.0pt |

**核心结论（本卡红线被数据完整验证）**：
1. 全部6个规则的样本外胜率一致回落到46%~47%区间——**在沪深300、5日前瞻、单规则维度上，
   阈值寻优挖不出稳健优势**，训练期提升基本是对噪声的拟合；
2. candle_div训练64.3%→测试45.7%是最典型案例，工具自动标记⚠️过拟合回撤；
3. 决策：**所有寻优参数不写回watchlist.yaml**（维持文献默认值），单规则阈值调优路线到此证伪；
4. 后续方向：单规则无优势≠组合无优势——screener的**多信号净分排序**（组合证据）
   才是下一步该回测的对象；以及把前瞻窗口从5日扩展到10/20日检验。
