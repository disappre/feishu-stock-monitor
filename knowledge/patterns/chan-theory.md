## 基础概念（实现口径；精确定义见理论基准卡）

```
K线包含合并(模糊合并): 相邻K线高低点包含时按方向合并（自实现merge_groups：
        向上取高高/向下取低低；绘图保留全部原始K线+框选合并组，499根→377单位/99组多根）
分型(FX): 合并后K线的局部顶(高点+两侧更低)/底(低点+两侧更高)；顶分型预示短期下跌
笔(BI): 顶底分型连线，两分型间至少一根独立K线（czsc bi_list）
线段(XD): 至少三笔重叠构成，更稳定的趋势单元；本项目用"特征序列分型简化"
        ——段内反向笔端点须逐个刷新极值，劣化即段终结【待验证】
中枢(ZS): 筹码密集震荡区，连续三次次级别走势的重叠区间[ZD,ZG]；市场多数时间
        在中枢内震荡或中枢间切换（czsc zs_list）
背驰(DIV): 趋势反转信号——顶背驰=价新高而MACD未同步(动能减弱)，底背驰镜像。
        本项目简化版：同向两笔对比，价格创新高/新低而MACD柱面积萎缩【待验证】
```

## czsc 1.0.1 API 坑（重要）

1. `str(b.direction)`返回**中文"向上/向下"**而非"Direction.Up"——方向判断必须用
   `b.direction == Direction.Up`枚举比较（本卡作者在此踩坑1小时）
2. `CZSC(bars)`老接口可用；`from_dataframe`要Arrow IPC字节，不适合直接喂DataFrame
3. **`bars_raw`不可直接当"合并K线"用**：实测有裁剪（120根输入只剩56根，起点漂移）
   且相邻之间仍存在包含关系——用于绘图会失真。正确做法：自行实现包含分组
   （标准规则：向上合并取高高max(high)/max(low)，向下取低低min/min），
   **画全部原始K线+框选多根合并组**，不吞并原始K线
4. Rust核心无内置线段对象——线段需自行实现（笔上直接二次CZSC会因相邻笔区间
   互相包含而失败，返回0笔）

## 双级别联立与信号失效（2026-09-11 用户指正后实现）

**失效机制**：现价处于任一日线中枢[DD,GG]区间内 → 所有三买/三卖信号失效不推送
（场景：旧中枢的三卖信号，价格已回到后续中枢震荡=反弹延续而非反转结构）；
信号笔距今超过 max_age_bars 笔视为过期。回测口径不传 last_px，历史回放语义不变。

**次级别分析**（自同构性落地）：`stock_monitor/engine/sublevel.py`
- 数据：腾讯 proxy.finance.qq.com mkline m30（注意 web.ifzq 的mkline会301到
  web3子域且该域DNS不通，必须走proxy端点）
- 逻辑：日线中枢内的股票，方向判断下沉到30分钟结构——次级别三卖="反弹衰竭"
  （日线下跌延续，本波属反弹）；次级别三买="回调企稳"
- 接口：机器人"次级别 600519"；全局模式 --sub 自动对中枢内个股附判断
- 实测（2026-09-11）：40只中枢内股票次级别均无三买卖结构（该结构本就低频）

**对三级分工体系的诚实判决**：

   与A股短期动量强的特性一致。教训：教学里的"铁律"经量化检验常是"强建议"；
3. 决策：rules_chan 加 direction_gate 配置（默认开——10pt增量+样本外
   顺段96.4%值得要），标注其性质是优化而非必须。

**严格性审查（三买91.7%经过了四道检验）**：
1. 时间线手工抽查（美的/潍柴案例）：信号日→次日开盘入场→第5日收盘，无前视
2. 日期分布：20个月均有信号，无单月集中（2025-09/10高峰=当时普涨行情，66/121）
3. 个股分散：87只，最大集中度仅4次
4. **+1根确认延迟的保守口径**（信号笔终点分型的右翼K线确认后才入场）：
   胜率91.7%→**87.6%**，均值+7.35%→+6.75%——仍然极强

**诚实保留**：信号月度分布与市场状态相关（2025-09/10占一半），样本期整体偏牛；
91.7%显著高于任何已验证信号，**建议实盘前向另两段历史窗口外推验证**。
三买与回测证伪的"看涨信号全灭"结论形成对照——缠论结构信号(基于中枢位置)与
单指标信号(基于价格动量)是不同性质的证据源。
