- 用途: 理论基准。工程实现的每一次修改都应以本文口径为准绳。

## 一、递归体系（第72课"懒人线路图"）

```
分型 → 笔 → 线段 → 最小级别中枢 → 各级别中枢/走势类型（递归升级）
```
- **图级别≠走势级别**（第63课显微镜原则）：1分钟图只是显微镜，"30分钟中枢"
  由三个连续次级别**走势类型**重叠构成，不是"30分钟图上的三笔重叠"
- **"线段以下没有中枢"**（第64课）：中枢由次级别走势类型构成；1分钟图上
  最小中枢由**线段**重叠构成，笔不能构成中枢

## 二、笔（第62/65/69/77课）

- 分型：包含处理后相邻三K线，中间K线高低点均极值（相等也算包含，第65课）
- 一笔四条件：①顶底相邻交替；②两分型不共用K线（结合律）；③**顶底之间至少
  一根独立K线**（第77课：不属于两个分型的K线）；④顶分型区间至少部分高于底分型
- 唯一划分三步骤（第77课）：标分型→连续同性质分型删前留后（前顶低于后顶时）→相邻异性质连笔
- **精度/宽严版本一旦选定必须全程一致**（第64课"取整"原则）
- 分型在图形未完成前可修改，完成后不可（第69课）——工程需支持增量更新不重写历史

## 三、线段（第64/65/67/71课）

- 至少三笔且**前三笔有重叠**；两端分型性质相反→笔数为奇数
- **线段只能被线段破坏**（单独一笔不能，第64课）
- 特征序列：向上线段取其**向下笔**序列（反之取向上笔）；做包含处理后为标准特征序列
- 分型三情况（第67课）：
  - 第一种：特征序列分型第一二元素间**无缺口**→线段在该分型处结束
  - 第二种：**有缺口**→需第二特征序列（从分型极值点起的反向笔序列）出现分型才结束；
    第二特征序列不再分第一二种
  - 第三种（第71课）：转折第一笔笔破坏时属"待定中间地带"；延伸三笔且第三笔破
    第一笔结束位置→新段成立；先破第一笔开始位置→旧段延续
- 分解定理：线段被破坏 ⟺ 被有重叠部分的连续三笔中某笔破坏 ⟺ 被另一线段破坏

## 四、中枢（第17/18/20/36课）

```
ZG/ZD: 前三个次级别走势A(a1,a2)B(b1,b2)C(c1,c2):
       ZG = min(a1,b1,c1)   ZD = max(a2,b2,c2)
GG = max(gn), DD = min(dn)  （中枢全部波动区间）
```
- **延伸**：任意[dn,gn]与[ZD,ZG]重叠；不超过9段否则自然升级（第36课）
- **新生（趋势）**：前后同级别中枢区间与波动**均不重叠**；后GG<前DD=下跌延续
- **扩张**：围绕连续两个同级别中枢的波动区间重叠→更大级别中枢（第20课定理二）
- **中枢破坏**（第18课定理三）：次级别走势离开后回抽**不重新回到中枢内**
  ——这就是三买/三卖的判定根源

## 五、背驰（第24/25/27/29/43课）

- **核心地位**：所有买卖点都由背驰产生（下跌背驰→一买，上涨背驰→一卖）
- **与传统背离的区别**：传统背离看价格vs指标偏离；**缠论背驰锚定中枢**——
  只有经过中枢盘整的背驰才有效，本质是比较**同一中枢前后两段（进入段vs离开段）的力度**
- 判定标准：离开段力度 < 进入段 = 背驰；力度未衰竭 = 行情延续

### 四类标准背驰（2026-09-13 用户视频教学补充，与原文课次吻合）

| 类型 | 结构 | 信号性质 | 操作建议 |
|------|------|---------|---------|
| 上涨盘整背驰（盘整上）| 一个上涨中枢后，向上离开段力度<进入段 | 短线卖出 | 确定性较低 |
| 下跌盘整背驰（盘整下）| 一个下跌中枢后，向下离开段力度<进入段 | 短线买入 | 轻仓 |
| 上涨趋势背驰（趋势上）| ≥2个同向上涨中枢后，最后离开段衰竭 | **最可靠顶部信号** | 重仓波段 |
| 下跌趋势背驰（趋势下）| ≥2个同向下跌中枢后，最后离开段衰竭 | **确定性最高买入** | 重仓波段 |

### 实战纪律（视频补充）

- 盘整背驰=短线信号快进快出；趋势背驰=大级别信号可重仓
- **"背了又背"陷阱**：大级别未走完时，小级别背驰只是中继——禁止小级别盲目抄底
- 结构正确+力度衰竭，背驰才有意义；结构错误时标准背驰也是陷阱

- **趋势背驰**：a+A+b+B+c结构（A、B同级别中枢）；前提=B段把**MACD黄白线回拉0轴附近**；
  判定=c段MACD柱面积（向上红柱/向下绿柱）**小于A段**
- 面积当下估算技巧（第24课）：柱子伸长变慢时"已出现面积×2"即可判断，不必等走完
- **盘整背驰**：比较第一段与第三段力度（不要求趋势结构）
- 关键约束：**背驰至少发生在第二个中枢之后**（第一个中枢后必不是趋势背驰，第27课）
- **背驰比较对象**：围绕同一中枢的**进入段与离开段**（b与c）——不是任意相邻两段
  （第64课110-111实例专门纠正此错误）
- 背驰-转折定理（第29课）三种结局：①最后中枢级别扩展（反弹仅及DD）②更大级别盘整
  ③以上级别反趋势；**趋势背驰的回跌一定至少回到B段中枢**
- 区间套（第27课）：大级别转折→次级别找背驰段→逐级收缩至最低级别精确定位

## 六、三类买卖点与完备性（第17/20/21/101课）

| 买点 | 精确定义 | 关键约束 |
|------|---------|---------|
| 一买 | 下跌趋势**确立后**、最后中枢下方的趋势背驰点 | 趋势未确立不存在；须第二中枢后 |
| 二买 | 一买后第一次次级别回调低点（第101课精确化：次级别回抽结束后再次探底/回试的次级别走势结束点） | 与三买可重合（V反最强）；与一买不可能重合 |
| 三买 | 次级别走势向上离开中枢后，**第一次**次级别回试，低点**不跌破ZG** | 必须第一次回试；比较对象是ZG不是GG；三买后也可能更大级别盘整但必然赢利 |

- **完备性定理**（第21课）：任何一点面临延续（→三买）或转折（→一买→二买），
  三类穷尽所有赢利买卖点；任何涨跌都从某类买卖点开始及结束
- 买卖点定律一：**任何二买都由次级别的一买构成**
- 买卖点级别定理（第35课）：大级别买卖点必然是次级别以下某级别的买卖点

## 七、走势终完美（第17/101/102课）

- 双重含义：走势最终完成；完成后必然转化为其他走势类型
- 本质=**递归函数将任何走势唯一分解**（唯一分解定理，第101课）
- 类似自然数记数法：**任何高级别改变必须先从低级别开始**（第102课）
- 操作意义：分段函数——买点买、卖点卖、之间持有（第68课"不测而测"）

## 八、操作纪律（第101-108课）

- **防狼术**（第103课）：回避所有MACD黄白线在0轴下的市场/股票
- **级别配资**（第35课）：操作级别定进出，次级别打短差降成本；
  "只有成本为0时才真正脱离风险"
- **上升趋势的精确定义**（第107课）：第一中枢后三买+非背驰向上，此前随时折回
- 机械操作（第105课）：只用"分型+能否延伸为笔"处理震荡；远离聪明
- 一般1/5/30分钟三级分解足够，大资金加日线（第102课）
