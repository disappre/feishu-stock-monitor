# 分形突破 + 双EMA趋势过滤（Fractal Breakout）

- 来源: https://www.mql5.com/zh/articles/18297 / 2026-09-09
- 关联代码: `stock_monitor/engine/rules_fractal.py`（已实现，测试 test_rules_fractal.py）

## 一句话结论

威廉姆斯分形定义关键位，只在EMA14/200确认的趋势方向上做突破确认，本质是趋势跟随而非预测。

## 核心规则

**分形（Bill Williams，5根结构）**：
```
分形高点 = 某根K线最高价 > 左右各2根K线的最高价（低点镜像）
右翼2根未走完 → 分形未确认，不得使用该水平位（防重绘）
```
**看涨信号（三条件同时满足）**：
```
① 前收盘 ≤ 分形高点水平 < 最新收盘（上穿突破）
② 最新价 > EMA14 且 > EMA200
③ EMA14 > EMA200（多头排列）
```
**看跌信号**：完全镜像（下穿分形低点 + 价格低于双EMA + EMA14<EMA200）。

## 适用与失效

- 适用: 趋势市的中段加仓/入场确认；分形高点天然代表近期真实阻力（有成交记忆的价位）
- 失效: 震荡市中价格反复穿越分形位，假突破密集——文章作者也建议配合其他过滤；
  A股跳空缺口会直接越过分形位（隔夜跳空突破无法用收盘穿越条件捕捉）
- 滞后性: 分形确认需右翼2根K线，水平位天然滞后2根；EMA200过滤又要求长期趋势已确立，信号偏晚——用"入场晚但方向对"换胜率

## 参数依据

- EMA 14/200、分形翼宽2：来自来源文章【待验证】；本项目未独立回测
- 工程注意: EMA200 要求≥200根历史，data/feed.py 的拉取长度已从60扩至250根
- 与现有规则的配合: ma_cross(5/20)抓中短期交叉，fractal_break(14/200)只抓长趋势中的结构突破，两者时间尺度互补不冲突
