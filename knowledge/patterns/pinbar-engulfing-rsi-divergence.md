# Pin Bar / 吞没形态 + RSI背离（双确认反转信号）

- 来源: https://www.mql5.com/zh/articles/17962 / 2026-09-08
- 关联代码: `stock_monitor/engine/rules_candlestick.py`（已实现，测试 test_rules_candlestick.py）

## 一句话结论

反转形态单用噪音大，配合RSI背离双重确认才发信号；本项目已代码化为 candle_div 规则。

## 核心规则

**Pin Bar**（以看涨为例，看跌镜像）：
```
阳线(close>open) 且 下影线 > 2×实体 且 上影线 < 0.5×实体 且 实体 > 10%×振幅
```
**吞没形态**：信号K线实体完全包住前一根实体（阳包阴=看涨，阴包阳=看跌）。

**RSI背离**（回溯窗口 5~15 根K线）：
```
看涨背离 = 价格新低（信号K线低点 < 窗口内低点）+ RSI低点抬高 + RSI < 30（超卖）
看跌背离 = 价格新高 + RSI高点降低 + RSI > 70（超买）
```
**发信号条件 = 形态 AND 背离同时满足**，单一条件不推送。

## 适用与失效

- 适用: 明确趋势后的反转捕捉；背离给出"动能衰竭"证据，形态给出"价位确认"
- 失效: 震荡市中RSI频繁进出超买超卖区，背离噪音大；【待验证】本项目A股数据下胜率未知，待多维表格流水回填
- 注意: 文章为MT5/外汇场景，A股有涨跌停制度（跌停无法成交），极端行情下信号与可执行性存在差异

## 参数依据

- 影线/实体比例 2.0/0.5/0.1、背离窗口 5~15、RSI 70/30：来自来源文章默认值【待验证】
- 与本项目已有 rsi 规则的区别：rsi 规则只看极值区，candle_div 要求极值区+背离+形态三重证据，信号更稀疏更高质量
