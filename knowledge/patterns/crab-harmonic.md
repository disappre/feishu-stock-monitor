# 螃蟹谐波形态（Crab Pattern）

- 来源: https://www.mql5.com/zh/articles/19099 / 2026-09-08
- 关联代码: `stock_monitor/engine/rules_harmonic.py`（待实现，见 Roadmap）

## 一句话结论

XABCD五点谐波形态，核心是D点位于XA的1.618倍延伸，属高胜率反转形态但需防重绘。

## 核心规则

以看涨形态为例（X低点起步，看跌完全镜像）：

```
XABCD 五点，均为左右各5根K线确认的枢轴点：
- B = A点回撤 XA 的 0.618（容差 ±10%）
- C = BC 幅度为 AB 的 0.382 ~ 0.886
- D = XA 的 1.618 倍延伸，且 D 必须低于 X（这是螃蟹区别于蝴蝶的关键）
- 触发: D点确认后的下一根K线才允许发信号（防重绘锁定）
```

与 Gartley/蝴蝶的区分：Gartley 的 D 只有 0.786 回撤（不到X），蝴蝶 D≈1.27 延伸，螃蟹 D=1.618 延伸最深。

## 适用与失效

- 适用: 震荡市与趋势末端的反转捕捉；配合成交量萎缩更可靠
- 失效: 单边强势行情中 D 点延伸后继续单边（1.618 失效后常走到 2.618）；枢轴点参数对高波动股需放宽，对低波动股需收紧——应按股性分桶调（见 strategies/ 股性分桶）
- 注意: 枢轴点右移确认（左右各5根）意味着信号天然滞后，D点出现时价格已离开低点，评估收益预期时要计入

## 参数依据

- 枢轴窗口 5 / 容差 10%：来自来源文章的默认值（作者回测所用），本项目尚未独立回测
- 止损设 TP2 距离的 3 倍反向：文章作者经验值，未验证
- 【待验证】需用多维表格信号流水统计本项目行情下的 D 点反转胜率
