## 一、MACD面积分离（已接入背驰检测，精度提升验证）

源码原文：
```
红面积:SUM(MACD,BARSLAST(MACD<0))*(MACD>0);
绿面积:SUM(MACD,BARSLAST(MACD>0))*(MACD<0);
```
**口径**：红面积=当前红柱段累计；绿面积=当前绿柱段累计——**红绿分离**。
等价实现：区间内按符号分离求和（`seg[seg>0].sum()` / `-seg[seg<0].sum()`）。

**为什么比原实现好**：原用 `abs().sum()` 把红绿混算，逆向柱会虚增动能，
导致"假背驰"漏报/误报。分离后严格对应缠师第24课"向上看红柱、向下看绿柱"。

**实证**（834只×2年，回放式）：
| | 混算(原) | 红绿分离(新) |
|---|---|---|
| 趋势下信号数 | 1263 | 994（-21%，更严格）|
| 测试期胜率 | 90.7% | **91.2%** |
| 训练期胜率 | 88.9% | 88.6% |
| 测试期均值 | +5.46% | **+5.69%** |

## 二、量能形态精确判定（已接入 volume_profile）

源码阈值：
```
倍量: V >= REF(V,1)*1.9               ← 放量基准1.9倍（含"假阴柱"也计）
倍缩: REF(V,1) >= V*1.9
平量: RANGE(V/REF(V,1), 0.97, 1.03)
百低: V = LLV(V,125) AND BARSCOUNT>=125
天量: V = HHV(V,0)
量王: 天量 AND 倍量 AND 量比>3 AND 上市>120日
长阴短柱: C/REF(C,1)<=0.96 AND V < HHV(V,30)/1.9  ← 大跌却缩量(惜售信号)
量比: V/REF(MA(V,5),1)
```
- 工程价值：**1.9倍**是有来源的放量基准（我们此前用1.15/1.5是拍的）；
- "长阴短柱"是八阶段表没覆盖的形态：跌6%以上但量不足30日最大量的1/1.9
  ——量价背离的惜售信号，可增强阶段2(洗盘)/8(被动吸筹)的判定。

## 三、多级别递归结构（2026-09-14 已实现）

源码机制解析 → 落地为 `stock_monitor/engine/chan_levels.py`：

```
递归链: L1(笔) → L2(线段) → L3 → L4
聚合规则(特征序列简化): 向上腿内反向点必须逐个抬升, 一旦劣化则腿终结于极值点
中枢: 连续三腿价格区间重叠 → ZG=min(各腿高), ZD=max(各腿低), ZG>ZD成立;
     向后吸收仍重叠的腿实现"延伸"
轨道: 红轨(下跌中新低驱动) / 绿轨(上涨中新高驱动) —— 对应源码X_122/X_127
```

**关键修正（踩坑记录）**：
1. 初版用"跌破腿起点"聚合 → 过于激进（云铝46点只剩4点）；
   改用与 build_segments 同源的"反向点劣化"规则 → 保留比约1/3（46→16→9→5）；
2. 初版多级别三买用**所有**中枢 → 出现"2024年中枢[10.16,11.08]判定2026年30元回试"
   的越界误判；修正为**只取末2个中枢 + 时效窗口（中枢后前5个次级别点）**。

**实测**：
| 股票 | 递归结构 | 末中枢示例 |
|------|---------|-----------|
| 云铝股份 | L1:46点 → L2:16 → L3:9 → **L4:5** | L1[25.11,27.61] red轨道 |
| 中兴通讯 | L1:42 → L2:14 → L3:4 | L2[34.02,39.08] green轨道 |
| 平安银行 | L1:43 → L2:17 → L3:7 | L2[10.93,11.04] 15腿长中枢 |
| 贵州茅台 | L1:32 → L2:13 → L3:5 | L1[1279.58,1338.86] red轨道 |

**接入**：MultiLevelRule（第13信号源，输出本级别三买/三卖+次级别确认）；
Web前端画出L2/L3/L4中枢轨道（虚线+颜色分级）+多级别买卖点标记（L23B/L33S等）。
