# Mamba选择性状态空间模型（长序列交易预测）

- 来源: https://www.mql5.com/zh/articles/19047 + [arXiv:2312.00752](https://arxiv.org/abs/2312.00752) / 2026-09-09
- 关联代码: 暂未实现（认知卡；对照聚类系统LSTM预测模块的技术演进）

## 一句话结论

Transformer的O(N²)注意力在长K线序列上算不动，Mamba用选择性状态空间模型(SSM)做到O(N)线性复杂度，2024-2025时序预测领域正从注意力架构转向SSM。

## 核心内容

```
痛点: 2048根K线 → Transformer约400万次注意力计算，秒级延迟；
     上下文长度被限制在512-1024时间点
Mamba(CMU, 2023.12): 选择性SSM，线性复杂度O(N)+高预测精度
趋势: 2024-2025时序预测从注意力转向状态空间模型；
     金融场景价值=多年度市场周期+品种联动的长序列分析
```

## 适用与失效

- 适用: 长历史依赖的策略（如经济周期级别规律）；多品种联动建模
- 失效/现实约束: MQL5端是作者手工实现的教学版；生产用Python生态
  (mamba-ssm库)。对日线监测(250根窗口)Transformer其实够用，
  Mamba的价值在分钟级长序列
- 与本项目关系: 聚类系统的 arima_lstm_predictor 用LSTM——Mamba是
  RNN家族的现代演进(选择性状态空间=可学习的遗忘门)。技术路线认知留档，
  若未来分钟级数据接入(实时bar已有)再评估
