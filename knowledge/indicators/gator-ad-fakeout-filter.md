# 鳄鱼振荡器 + AD指标：假突破双重过滤

- 来源: https://www.mql5.com/zh/articles/18992 / 2026-09-09
- 关联代码: 可落地为 `engine` 信号过滤器的思路（与现有 fractal_break 直接互补）

## 一句话结论

趋势指标(鳄鱼/Gator)发出信号但成交量指标(AD)不确认 = 假突破；两指标同向才认，ADX式"双重确认"思想可直接增强现有突破规则。

## 核心规则（形态5：虚假突破/趋势陷阱）

```
多头陷阱识别: 鳄鱼振荡器翻绿(颚/牙/唇张开,趋势信号) + AD线平缓或走低
             = 无真实资金流入的诱多假突破
陷阱化解确认(入场): 价格未下破反而收复突破区间 + 鳄鱼嘴仍张开
                  + AD转入上升明显走强 → 双重确认的多头入场
```

## 适用与失效

- 适用: 直接解决本项目 `fractal_break` 的已知弱点——知识卡片
  (fractal-ema-breakout.md)已记录"震荡市假突破密集"。文章提供了
  量能确认的具体形态：价格突破时AD(累积/派发线)必须同步走高
- 失效: 文章GBPJPY 30分钟测试中形态0/3/4滚动外推表现不佳——
  **作者诚实披露了部分形态样本外失效**，值得学习这种测试纪律
- 落地建议: 给 fractal_break_up 信号加"AD线走高"确认条件，
  作为可选开关(AD过滤)加入 watchlist.yaml，A/B对比有/无过滤的信号胜率
