# 灰色模型 GM(1,1) 交易预测

- 来源: https://www.mql5.com/zh/articles/19012 / 2026-09-09
- 关联代码: 暂未实现（候选：与聚类系统的 improved_arima 并列做预测对照）

## 一句话结论

对短序列(≥4个正数)做累加生成(AGO)降噪后用一阶微分/递推方程外推，适合小样本、无明显分布假设的短期预测。

## 核心规则

```
适用前提: 序列长度≥4、全部为正数、等间隔采样、无缺失
1. AGO累加生成: x_ago[i] = sum(x[0..i]) —— 降噪 + 使序列严格递增、可预测性提升
2. GM(1,1): 一阶微分方程描述累加序列；解析解需符号数学系统(Maple)
3. 离散GM(推荐): 递推方程 x(n+1) = a*x(n) + b
   —— 避免解析解的数值不稳定（小数点微差可致图表失效），参数估计即线性回归
4. 预测后需做AGO逆运算(累减还原)得到原尺度预测值
```

## 适用与失效

- 适用: 小样本(4~10点)、数据噪声大、不满足统计模型分布假设的短期外推
- 失效: 序列含负数或零（价格序列需先平移或用收益率小心处理）；长期多步外推误差快速累积；A股跳空/涨跌停等结构断点会破坏"等间隔光滑"假设
- 与ARIMA关系: GM(1,1)是无分布假设的小样本方法，可与聚类系统已有的 improved_arima 做预测对照实验——两者都已在知识库留档
