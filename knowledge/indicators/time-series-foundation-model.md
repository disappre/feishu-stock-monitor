# 时序基础模型与零样本预测（TimeFound）

- 来源: https://www.mql5.com/zh/articles/18414 + [arXiv:2503.04118](https://arxiv.org/abs/2503.04118) / 2026-09-09
- 关联代码: 暂未实现（定位：技术路线认知卡；对照聚类系统的预测模块）

## 一句话结论

借鉴LLM预训练范式的时序Foundation Model：多域数据(股价/电力/失业率)联合预训练一个Transformer，实现小样本/零样本时序预测。

## 核心内容

```
动机: 深度模型需海量标注数据；新上市标的/新代币没有历史 → 零样本预测
路线: NLP基础模型思想 → 时序基础模型(TimeFound)
     多元化数据集充分预训练 → 单一通用模型跨域预测
架构: Transformer（细节见arXiv原文）
```

## 适用与失效

- 适用: 历史极短的新标的（新股上市场景A股常见）；跨域迁移（用电量模型迁移到价格）
- 失效/现实约束: **MQL5端实现是作者的教学复刻**，生产级时序基础模型
  (TimeGPT/Chronos/Moirai等)体积大、需GPU；个人项目直接调用API
  (如TimeGPT)比复现更现实
- 与本项目关系: 聚类系统已有 ARIMA/LSTM 预测模块。基础模型路线的价值
  在"新股无历史"场景——聚类模型同样需要历史窗口(30根)，次新股是盲区。
  认知卡先留档，不急于落地
