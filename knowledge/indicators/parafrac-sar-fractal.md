# Parafrac振荡器（抛物线SAR×分形组合）

- 来源: https://www.mql5.com/zh/articles/19100 / 2026-09-09
- 关联代码: 暂未实现（认知卡；与现有 fractal_break 的分形部分重叠）

## 一句话结论

把抛物线SAR(趋势方向/反转点)与威廉姆斯分形(价格极值)融合成单一振荡器，取两者协同：SAR定位趋势，分形定位关键位。

## 核心内容

```
SAR(1978, Wilder): 圆点在K线上方=卖出信号，下方=买入信号；趋势市利器，震荡市反复打脸
分形: 左右各2根确认的局部极值(本项目 fractal_break 已实现)
组合逻辑: SAR定方向 + 分形定入场价位 → 振荡器形态化
```

## 适用与失效

- 适用: 趋势市的反转点位捕捉；与现有规则不冲突但高度重叠——
  fractal_break 已用"分形位+EMA趋势"组合，Parafrac 用"分形位+SAR方向"，
  差异仅在趋势判定器(EMA200 vs SAR)
- 失效: SAR在震荡市会产生连续假反转信号（Wilder本人也承认），
  震荡市过滤仍是未解问题
- 落地价值评估: **优先级低**。现有8规则已覆盖其能力域；
  除非未来做"趋势判定器对比实验"(EMA vs SAR vs ADX)才有引用价值
