# 高斯过程分类（概率化信号置信度）

- 来源: https://www.mql5.com/zh/articles/18875 / 2026-09-09
- 关联代码: 暂未实现（定位：信号置信度升级路线的候选方案）

## 一句话结论

GP分类输出"75%概率上涨"而非硬标签——概率预测天然适合过滤不可靠信号，与本项目Signal.confidence字段理念完全同构。

## 核心内容

```
GP分类 vs SVM/决策树: 后者只输出类别标签，GP输出概率分布
金融映射: P(上涨)=75% → 用置信度过滤信号、辅助仓位决策
实现难点: 分类推断无封闭解(非高斯似然) → 拉普拉斯近似
工程: 模块化库设计(GaussianProcess类+优化目标类分离)
```

## 适用与失效

- 适用: 本项目聚类信号(confidence=距离倒数)和形态信号(0.85等)的
  置信度目前是启发式定义；GP提供有概率论根基的替代：
  特征(21维金融特征已有)→GP分类→P(涨)，可直接当Signal.confidence
- 失效: GP计算复杂度O(N³)样本数大时不可行（300只×250天需近似方法）；
  拉普拉斯近似的质量依赖先验选择
- 落地评估: 中优先级。比DRL/量子路线现实得多，且与现有
  ImprovedKMeans特征管道直接兼容(特征复用，换分类头)
