# Mantis轻量时序分类基础模型（校准置信度）

- 来源: https://www.mql5.com/zh/articles/18246 + [arXiv:2502.15637](https://arxiv.org/abs/2502.15637) / 2026-09-09
- 关联代码: 暂未实现（认知卡；与GP分类卡同为"信号置信度"路线候选）

## 一句话结论

面向"市场状态分类"（而非数值回归）的轻量基础模型：对比预训练+局部/全局token混合注意力降复杂度，核心卖点是概率校准——输出的置信度是真实概率，可直接用于风控。

## 核心内容

```
定位区分: 预测模型(回归:明天的价格) vs 分类模型(状态:当前是头肩顶/双底)
Mantis: 时序切patch + 视觉Transformer思路 + 局部token+全局token
       (避免全局注意力O(N²)瓶颈) + 对比预训练
关键能力: 概率校准(calibration)——说70%就是70%，未校准模型说70%实际可能只有55%
```

## 适用与失效

- 适用: 本项目聚类形态识别的现代化替代路线：现在K-means对形态分类，
  Mantis式对比学习可学到更判别性的形态表征，且天然输出校准置信度
- 失效: 需预训练数据与GPU；A股形态标注数据集不存在(需自标)；
  校准在分布漂移(如政策突变)后会失效，需定期重校准
- 与GP分类卡的关系: GP=小样本+理论概率但O(N³)；Mantis=大数据+校准经验概率。
  两者都指向同一个项目演进方向：**Signal.confidence从启发式升级为校准概率**
