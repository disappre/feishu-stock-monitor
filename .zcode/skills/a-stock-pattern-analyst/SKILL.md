# A股个股技术形态分析

把用户给的股票代码变成一份"数据驱动 + 知识库背书"的个股体检报告。

## 工作流程

### 第1步：获取真实分析数据（必须执行，禁止凭记忆编造行情）

在 feishu-stock-monitor 仓库根目录运行：

```bash
python skills/a-stock-pattern-analyst/scripts/analyze_once.py <股票代码>
```

输出 JSON 包含：现价快照、均线/量能/RSI 概览、触发的信号列表（含来源与置信度）。
脚本失败时如实告知用户数据不可用，**绝不虚构行情数字**。

### 第2步：对照知识卡片解读

- 触发了形态类信号（`pattern_` 前缀）→ 必须读取 `knowledge/patterns/<对应卡片>.md`，
  引用其中的"核心规则"解释为什么触发、"适用与失效"提示当前环境的可靠性；
- 知识卡片中标注【待验证】的参数，输出时必须原样保留该标注，不得悄悄当作已验证结论；
- 知识库里没有对应卡片的信号，用规则引擎返回的 detail 原文，不要自行发挥技术含义。

### 第3步：按固定结构输出

```
## <名称> <代码> · <现价> (<涨跌%>)
**快照**：均线排列 / 量能倍数 / RSI / 近30日涨跌
**触发信号**：<每条信号一行，含置信度；无则说明各指标正常>
**知识库解读**：<引用卡片的适用与失效条件>
**风险提示**：仅供学习研究，不构成投资建议
```

## 红线

1. 只做事实陈述、指标解释、形态统计复述，**禁止任何买卖/仓位/止损建议**；
2. 行情数据只来自脚本输出，报告中的每个数字必须可追溯到数据或知识卡片；
3. 用户要求预测涨跌时，明确说明系统只做形态与统计识别，不做方向预测。
